# Fluent 串口助手 v0.1.12

此版本扩展快速绘图的数据解析能力，并统一界面、CLI 与 MCP 的解析配置模型；同时修复 Fluent 图标的可见边界对齐问题，优化解析设置表格和默认终端字号。

## 快速绘图解析

- 支持多行记录、多词和 Unicode 键值字段、嵌套 JSON 及目标字段筛选。
- 二进制数据可从完整帧或协议载荷读取，字段支持字节偏移、有/无符号整数、浮点、大小端、比例和加值。
- 解析设置使用 Fluent 表格和下拉组件，重新分配列宽并统一单元格留白。
- CLI 与 MCP 绘图接口同步支持目标字段、二进制来源和字段定义参数。

## 界面与兼容性

- 默认终端字号由 10 调整为 14；已有用户保存的字号保持不变。
- Fluent 图标引擎依据 SVG 可见像素边界居中，主页和快速绘图工具栏统一交叉轴中心线。
- UI 中不展示 CLI/MCP 实现说明，解析配置保持面向串口数据本身。

## 验证

- Qt 6.11.1 macOS Debug 完整构建通过。
- C/C++ 格式检查、翻译 XML 校验及 Git 差异检查通过。
- 在实际调试构建中验证二进制字段新增、表格布局和辅助功能树读取稳定。
