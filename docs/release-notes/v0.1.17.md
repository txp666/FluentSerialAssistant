# Fluent 串口助手 v0.1.17

此版本增加独立曲线窗口和可视化帧协议编辑器，修复终端随窗口宽度换行及侧栏卡片展开拖影，并使用最新正式发布的 FluentQtWidgets v0.1.9。

## 独立曲线窗口

- 每次点击曲线图标，都先选择解析协议并确认，再创建新的曲线窗口。同一会话可以同时打开多个窗口，各自选择协议和字段。
- 支持全部既有解析类型：全部数字、分隔值、键值对、JSON 对象和二进制字段。可输入文本/HEX 样例查看解析值，并选择需要绘制的字段。
- 二进制字段支持整数和浮点类型、字节偏移、大小端、比例和数值偏移；可从完整帧取数，或选择保存的帧协议模板并从通过校验的载荷中取数。
- 曲线仅采集窗口打开期间的新接收记录。隐藏、最小化或关闭后停止取数和绘制；新窗口从空曲线开始，不载入打开前或关闭期间的历史记录。
- 各窗口保留暂停、清空和 CSV 导出功能。

## 可视化帧协议编辑器

- 左侧“协议模板”中点击“编辑协议”，打开独立窗口，按名称与帧头、长度、命令、载荷和校验分组配置协议。
- 输入样例 HEX、使用内置示例或最新接收帧，查看彩色字节结构、字段位置、解析值和校验结果；编辑字段或样例即可更新预览。
- 支持新建、保存、删除模板和保存样例。无效字段配置、异常帧长度或错误样例会显示原因，帮助检查协议。
- 编辑器使用 Fluent 滚动组件，整理左侧字段和底部操作栏。

## 终端与侧栏

- 连续接收文本随窗口宽度重新换行，放大窗口后不再保留旧行宽，并保持搜索及数据表格到终端的记录定位。
- 清空扫把按钮移到终端工具栏最左侧、流量统计之前，同时清空终端显示并重置收发流量计数。
- 移除右上角窗口控制按钮、流量与连接状态区域及文字控件的悬停提示，保留图标操作提示。
- 修复侧栏已有滚动条时，展开下方卡片产生的布局重叠和拖影。
- FluentQtWidgets 更新至正式版 v0.1.9，包含卡片展开动画、快速反向展开/收起及滚动条同步修复。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。
