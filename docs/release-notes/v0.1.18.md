# Fluent 串口助手 v0.1.18

此版本以稳定性和数据正确性修复为主：解决长宏命令崩溃、关闭会话卡顿、多会话配置互相覆盖和多字节字符乱码，修正硬件流控、帧头断帧、收发记录顺序、Modbus 数量上限和校验算法等问题，修复曲线窗口与帧协议编辑器的多处状态问题，并精简曲线窗口工具栏。

## 稳定性

- 没有延时的长宏命令序列不再因逐步嵌套调用导致程序崩溃。
- 关闭正在运行脚本的会话时不再卡住约 2 秒；脚本停止后，停止前排队的发送请求不会再发出。
- 同时打开多个会话时，发送历史、数据包、宏步骤、自动应答规则和协议模板不再互相覆盖，任一会话保存后其他会话同步更新。
- UTF-8、GBK 等多字节字符分两次读取到达时，不再显示为乱码。

## 串口收发

- 使用硬件流控时，连接不再弹出两条串口错误；RTS 由驱动控制，连接期间“RTS”选项不可用。
- 帧头断帧模式下，最后一帧在线路空闲超过断帧间隔后立即显示，一问一答的设备不再等到下一个帧头才看到回复。
- 自动应答和宏发出的记录排在触发它的接收记录之后。
- 循环发送的内容无效或发送失败时，只提示一次并自动停止循环。
- 文件发送按串口实际写出的速度分块，进度、取消和完成状态与实际发送一致。
- 勾选“保存接收”后，不再在每次启动时生成空的捕获文件。
- 自动应答规则一直不匹配时，不再对每次接收重扫最多 1 MiB 的缓冲；修改终端记录上限会立即应用到已打开的会话。

## Modbus 与校验

- Modbus 写多个线圈/寄存器的数量上限改为 1968 和 123，保证请求放得进一个 RTU 帧。
- 校验算法名称无效时（包括协议模板中）会提示不支持，不再静默按 CRC16-Modbus 校验。
- 英文界面的 Modbus 状态不再整句转成大写，并修复英文界面多处分隔符“·”显示为“?”。

## 曲线窗口

- 工具栏精简：协议按钮直接显示当前协议并打开解析设置；清空、复位视图和导出 CSV 改为图标按钮；状态信息移到图表下方，窄窗口下不再被截断。
- 新建曲线时带出上次应用的解析配置，包括字段筛选和二进制字段。
- 解析设置切换到二进制协议时，样例在文本和 HEX 之间转换；切换协议时清空字段筛选，避免新曲线一直为空。
- 通过 CLI/MCP 显示曲线时只复用控制接口自己打开的窗口，不再改动并清空用户正在使用的曲线窗口。
- 最多显示 32 个通道；未配置字段的二进制数据按前 32 个字节绘图，超出时状态栏会提示。
- 导出保存的数据与曲线保留的点数一致，长时间绘图不再持续增加内存；粘贴很长的样例时只预览前 64K 字符，输入保持流畅。

## 帧协议编辑器

- 实时解析使用已保存的选中模板，编辑器中未保存的修改不再影响接收记录的协议标注。
- 点击“新建”会重置全部选项；切换到没有保存样例的模板时，自动生成适合该模板的示例帧；“内置示例帧”按当前模板生成。
- 编辑器关闭期间也会记录最新接收帧，打开后可直接使用“最新接收”。

## 脚本、控制与更新

- 脚本中调用 `serial.log()` 不再清空 `serial.lastError()`。
- macOS 和 Linux 上，本地控制服务改用当前用户私有的运行目录，其他用户无法抢先创建同名连接并接收 `fluentserial-cli` 和 `fluentserial-mcp` 发送的命令与记录。`fluentserial-cli`、`fluentserial-mcp` 需与应用使用同一版本，安装包内附带的版本已同步更新。
- 新版本刚发布、安装包尚未上传完成时，检查更新会提示安装包尚未就绪；发布流程在全部安装包上传后才将版本标记为最新。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。
