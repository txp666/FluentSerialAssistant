# Fluent 串口助手 v0.1.24

- Windows 11 上开启“云母效果”后，标题栏和卡片之间透出云母背景，窗口激活时显示壁纸的色彩。
- 曲线窗口、数据表格和帧协议编辑器的标题栏跟随应用的主题切换。
- 帧协议编辑器的样例帧和字节视图、曲线解析设置的样例输入恢复为与周围输入框一致的字号。
- 界面控件库升级到 FluentQtWidgets v0.3.0，Qt 运行库升级到 6.12。

## English

- With Mica on in Windows 11, it now shows through the title bar and between the cards, tinted by the wallpaper while the window is active.
- The title bars of the plot, frame table and protocol editor windows follow the app's theme.
- The protocol editor's sample frame and byte view, and the plot settings' sample, are back to the size of the inputs around them.
- FluentQtWidgets v0.3.0 and Qt 6.12.
