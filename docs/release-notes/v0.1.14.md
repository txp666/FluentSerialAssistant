# Fluent 串口助手 v0.1.14

此版本加入应用内更新：先查看更新内容并确认，再下载、校验和安装。

## 更新流程

- 启动后自动检查更新，离线或没有新版本时不弹窗；也可在“设置 → 应用更新”手动检查。
- 发现新版本后展示版本号和更新说明。点击“下载并安装”才开始下载，选择“稍后”可暂不更新。
- 后台使用 4 路并行连接，显示下载百分比、已下载大小和状态。服务器不支持分段下载（HTTP Range）时自动改用单连接；下载可取消，失败后可重试。
- 下载完成后核对文件大小和 SHA-256，通过后准备安装。Windows、macOS 和 Linux DEB 安装按需请求系统授权。
- 安装交接成功后保存配置并正常退出，由安装程序完成更新，无需再次在应用内确认。下载或安装准备失败时，应用保持运行。

## 从旧版本升级

完整的应用内更新流程从 v0.1.14 起提供。使用 v0.1.13 或更早版本时，请先从发布页手动下载并安装本版本；之后可通过应用内更新获取后续版本。

- 已实际从 GitHub 下载安装包，并验证文件大小和 SHA-256；测试未执行真实安装。
