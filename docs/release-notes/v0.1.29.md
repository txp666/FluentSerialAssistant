协议模板、实时解析和曲线已打通，同一串口上的多个设备可以按地址分别查看和绘图（[#20](https://github.com/txp666/FluentSerialAssistant/issues/20)）。

- 在“编辑协议”中定义载荷字段、数值类型、字节序、倍率、加值和设备地址，保存后勾选“启用”即可查看实时数值，勾选字段绘制曲线。
- 字节图始终显示，字段列表使用对应颜色，支持拖动调整数据字段顺序；模板与字段设置集中在右侧，实时解析窗口的左侧配置可收起。
- 自动生成匹配协议的样例并更新长度、校验。粘贴 HEX 或使用“最新接收”后会保留样例原始字节；清空后继续编辑可恢复自动生成。
- 编辑器的“创建曲线”和终端的曲线入口共用模板字段。保存同名模板后，关联曲线同步配置并清空旧数据；保存其他模板不影响当前曲线草稿。
- 分批接收的数据按模板重组，多帧连续到达也可解析；重连时丢弃未收齐的半帧，保留已有曲线历史。没有长度信息的模板仍需配置接收断帧。
- 修复 Qt 6.12.0 数值输入框显示、macOS 动态表格辅助功能崩溃和表格排序箭头缺失问题。

## English

Protocol templates, live analysis, and plots now share field definitions. Devices on the same serial bus can be inspected and plotted separately by address ([#20](https://github.com/txp666/FluentSerialAssistant/issues/20)).

- Define payload fields, types, byte order, scale, add values, and the device address in **Edit protocol**. Save and check **Enable** to view live values, then check fields to plot them.
- The byte map stays visible, with matching colors in the field table and drag-to-reorder data rows. Template and field settings stay on the right; the live analysis configuration panel can be hidden.
- Matching samples are generated automatically with updated length and checksum. Pasted HEX and **Latest received frame** samples retain their original bytes while settings change. Clear the sample and continue editing to resume generation.
- **Create plot** in the editor and the terminal's plot button use the same template fields. Saving the same named template updates linked plots and clears old data; saving another template leaves the active plot draft intact.
- Frame assembly handles split reads and multiple frames per read. Reconnecting discards incomplete frames while retaining plot history. Templates without length information still require receive framing.
- Fixed invisible spin box values on Qt 6.12.0, a macOS accessibility crash with dynamic tables, and missing table sort arrows.
