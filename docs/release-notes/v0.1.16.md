# Fluent 串口助手 v0.1.16

此版本增加通用终端内容着色，简化终端搜索与状态栏，并调整发布构建的触发方式。

## 内容着色

- 在 **设置 → 内容着色 → 配置** 中按关键词或正则表达式设置颜色，支持区分大小写、仅着色匹配内容或着色整行。
- 提供四组可独立勾选的示例：ESP-IDF 日志前缀、通用日志等级、成功与失败、AT 指令响应。
- 自定义规则优先于示例预设，列表上方的规则优先；可通过排序调整重叠匹配的颜色。
- 配置会保存并应用于所有终端会话，接收和发送内容均可着色，并保留搜索匹配高亮。

## 终端界面

- 搜索框改为固定在终端右上角的紧凑半透明搜索栏，无需拖动。支持 Ctrl/Cmd+F 打开、Enter/Shift+Enter 切换匹配，以及 Esc 关闭。
- 状态栏按接收、发送、连接信息分区，使用 `R↓`、`T↑` 展示速率，并在下方显示累计流量。
- 状态信息随窗口宽度压缩，数值使用固定宽度和等宽数字，避免流量变化时布局跳动。

## 发布流程

- GitHub Actions 仅在发布 GitHub Release 时运行测试和打包，不再由提交、Pull Request、标签推送或手动操作触发。
- 继续提供 Windows x64、macOS arm64、Linux x64/arm64 安装包及对应的 SHA-256 校验文件。所有平台完成构建并通过产物校验后，统一上传到 Release 并标记为最新版本。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。
