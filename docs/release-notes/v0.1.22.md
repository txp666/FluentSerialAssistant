# Fluent 串口助手 v0.1.22

此版本处理 v0.1.21 的使用反馈（#9）：自动应答可以复制已有的应答，添加后直接进入新建；侧边栏中的列表可以用鼠标滚轮滚动；修正深色主题下“跳过字节”输入框的边角，以及下拉框展开时的闪烁。

## 自动应答

- 新增“复制”按钮：以选中的应答为模板新建，匹配、应答内容、延时等设置都沿用，名称后加“副本”，并选中匹配内容方便直接修改。改好后点“添加”才保存，因此不会留下两条相同的应答对同一数据各回复一次。
- 添加成功后直接进入新建状态，列表滚动到刚添加的应答，可以接着填写下一条，不用再点“新建”。

## 修复

- 深色主题下，发送设置“跳过字节”的两个输入框底边被截掉，只剩两端的浅色圆角，看起来像白色边角；现在与其他输入框一致。
- 侧边栏中的自动应答、常用包和宏列表，以及内容超出的编辑框，无法用鼠标滚轮滚动，滚轮总是滚动整个侧边栏；现在先滚动鼠标下的列表或编辑框，滚到头后再滚动侧边栏。
- 点击波特率、串口号等下拉框时，下拉列表经常先在下拉框上方闪现一下再展开（Windows 上较明显）；现在列表直接从下拉框下方展开。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。
