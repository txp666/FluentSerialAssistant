# Fluent 串口助手 v0.1.22

处理 v0.1.21 的使用反馈（#9）。

- 自动应答新增“复制”，以选中的应答为模板新建；添加后直接进入新建状态，可接着填写下一条。
- 侧边栏中的自动应答、常用包和宏列表可以用鼠标滚轮滚动。
- 修复深色主题下“跳过字节”输入框底边被截掉、看起来边角发白的问题。
- 修复点击下拉框时列表先在上方闪现的问题（Windows 上较明显）。

v0.1.14 及更新版本可在应用内检查更新；更早的版本请从发布页手动下载安装包。

## English

Addresses the v0.1.21 feedback in #9.

- Auto reply: a new "Copy" button starts a new rule from the selected one, and after a rule is added the editor is ready for the next.
- The auto-reply, packet and macro lists in the side panel now scroll with the mouse wheel.
- Fixed the skip-byte inputs in dark theme, whose clipped bottom border looked like white corners.
- Fixed drop-down lists flashing above the combo box when opened, mostly seen on Windows.

v0.1.14 and later can update from inside the app; earlier versions need the installer from the releases page.
