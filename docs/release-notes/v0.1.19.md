# Fluent 串口助手 v0.1.19

此版本以安全和界面修复为主：自动更新只安装经过校验、当前用户无法改动的安装包副本，Windows 上的本地控制服务按用户隔离；主窗口适应小屏幕和高缩放比例，切换主题更快、Windows 11 上窗口背景不再闪动，曲线键值解析在长行上保持流畅，并修复界面组件库的多处崩溃和交互问题。

## 安全

- 自动更新的安装步骤以管理员权限运行，现在只从它自己创建、当前用户无法修改的目录安装：先把安装包复制进去，按发布信息中的 SHA-256 校验这份副本，再只安装这份副本。macOS 和 Linux 上的安装脚本直接通过命令行传入，不再写入用户目录。此前，同一用户下运行的其他程序有机会在系统授权之后、安装之前替换安装包或脚本，借此以管理员权限运行。
- Windows 上，上述目录位于系统提供的 ProgramData 位置，不再读取可被用户修改的环境变量，并且只在路径上仅系统和管理员能改动的位置创建。
- Windows 上本地控制服务按用户隔离：`fluentserial-cli` 和 `fluentserial-mcp` 只连接属于当前用户的服务，同一台电脑上的其他用户无法抢先占用连接、接收命令与串口数据。

## 界面

- 小屏幕或高缩放比例下（例如 1920×1080 缩放 150%），主窗口的最小尺寸和初始尺寸按屏幕可用区域缩小，标题栏按钮不再超出屏幕；窗口移到较小的屏幕时会缩小并移回屏幕内。
- 发送框等多行输入框内容滚动后，焦点下划线保持在输入框底部。
- 切换主题时只立即更新正在显示的界面，其他页面在显示时再更新，切换更快。
- Windows 11 上切换主题时窗口背景不再闪一下。
- 界面组件库修复了多处在对象删除后仍被使用、可能导致崩溃的问题，以及滑块、进度条、下拉框、滚动条和提示等控件的多处显示与交互问题。

## 曲线与更新

- 曲线的键值解析遇到很长且没有 `:` 或 `=` 的行时不再卡顿，也不再丢失行尾的字段；由八个以上单词组成的字段名保持完整。
- 自动更新的安装程序在准备阶段失败时立即报告，应用不再停在“正在安装”状态等待约三分钟。
- Windows 上，应用从 PowerShell 7 中启动时，更新安装脚本可能加载到 PowerShell 7 的模块而安装失败；脚本现在只使用 Windows PowerShell 自带的模块。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装；更新到 v0.1.19 仍由已安装版本的更新程序完成，新的安装流程从下一次更新开始生效。v0.1.13 及更早版本请从发布页手动下载安装包。

Windows 上本地控制服务的连接名称已变更，`fluentserial-cli`、`fluentserial-mcp` 需与应用使用同一版本，安装包内附带的版本已同步更新。
