# Fluent 串口助手 v0.1.25

macOS 安装包改为通用版，Intel Mac 也能安装和使用。

- macOS 下载改为一个通用 DMG（`macos-universal.dmg`），同时支持 Apple 芯片和 Intel Mac，取代只支持 Apple 芯片的 arm64 DMG。
- Intel Mac 上同样可以在应用内更新。
- 同一个 DMG 另以 `macos-arm64.dmg` 的名字发布，v0.1.24 及更早版本可照常在应用内更新到此版本。

## English

The macOS package is now universal, so Intel Macs can install and run it too.

- The macOS download is one universal DMG (`macos-universal.dmg`) for Apple silicon and Intel Macs, replacing the Apple-silicon-only arm64 DMG.
- Intel Macs update from inside the app as well.
- The same DMG is also published as `macos-arm64.dmg`, so v0.1.24 and earlier still update to this version from inside the app.
