修复超时断帧把连续数据拆成单字节的问题（#15）。

- 超时时间内连续收到的字节合成一帧，显示在一行；协议解析、数据表格和快速绘图也按整帧处理。
- 一帧在线路空闲超过超时时间后显示。
- 超时断帧时，自动应答和宏的回复仍记在请求之后。

## English

Fixes timeout framing splitting a continuous reply into single bytes (#15).

- Bytes received within the timeout form one frame on one line; protocol parsing, the data table and the quick plot work on whole frames too.
- A frame appears once the line has been quiet for the timeout.
- With timeout framing, auto-replies and macro replies are still logged after their request.
