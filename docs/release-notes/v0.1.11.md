# Fluent 串口助手 v0.1.11

此版本新增面向 AI 和自动化脚本的本机控制架构。GUI 继续统一持有串口，CLI 与 MCP 通过用户级本地 IPC 复用现有会话、协议解析、收发记录和快速绘图能力。

## AI、CLI 与 MCP

- 增加版本化的本地 JSON IPC 服务，使用 `QLocalServer`/`QLocalSocket`，仅允许当前系统用户访问。
- 增加 `fluentserial-cli`，提供端口和会话查询、连接/断开、文本/HEX 发送、记录读取、协议模板选择及绘图窗口控制。
- 增加 `fluentserial-mcp` stdio 服务，提供 12 个可发现工具、JSON Schema 参数和结构化调用结果。
- MCP 支持 `2025-11-25`，并兼容 `2025-06-18`、`2025-03-26` 和 `2024-11-05` 协议版本。
- 多会话可通过稳定会话 ID 查询和选择；未指定会话时默认操作 GUI 当前会话。

## 协议与曲线

- 启用二进制协议模板后，CLI/MCP 读取 RX 记录会返回命令字、载荷、帧长和校验结果。
- AI 可打开快速绘图窗口，并在全部数字、分隔值、键值对和 JSON 对象取值模式之间切换。
- 二进制协议模板与文本绘图协议保持独立，避免在缺少字段类型、比例和单位定义时猜测物理量。

## 架构与发布

- 新增独立 `SessionControl` 领域接口、控制服务、IPC 传输层以及 CLI/MCP 薄适配器。
- Windows、macOS 和 Linux 安装包均包含 CLI 与 MCP 可执行文件。
- macOS 部署会修正 CLI/MCP 的 Qt Framework 引用；Linux 为两个程序配置相对 RPATH 和 DEB 命令入口。
- 增加完整的 AI 控制、CLI、MCP 工具及 IPC v1 契约文档。

## 验证

- Qt 6.11.1 macOS Debug 完整构建和格式检查通过。
- CLI 已通过真实 GUI IPC 查询端口、会话、状态和协议模板。
- MCP 已完成初始化、工具发现及 `serial_get_status` 端到端调用。
- macOS 安装目录验证确认 CLI/MCP 使用应用包内 Qt Framework，不依赖开发环境。
