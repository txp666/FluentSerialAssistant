# Fluent 串口助手 v0.1.15

此版本修复终端搜索时的滚动跳转，并改善搜索窗口的操作与布局。

## 终端搜索

- 修复搜索后收到新数据会跳回旧匹配项的问题（[#2](https://github.com/txp666/FluentSerialAssistant/issues/2)）。关闭自动滚动时保留阅读位置，开启时跟随最新数据；输入搜索条件或点击上一个、下一个匹配时才定位结果。
- 搜索期间增量追加终端内容，避免重复重建整段日志。
- 修复清空记录、历史记录达到上限及多行记录裁剪后的匹配位置和导航状态。

## 搜索窗口

- 改为带标题栏的独立工具窗口，支持移动，点击终端或其他控件时不会自动关闭。
- 关闭后重开保留窗口位置和搜索内容；支持 Esc 关闭，切换会话时隐藏对应窗口。
- 修正图标与文字的垂直居中，兼容浅色和深色主题。
- 移除内部悬停提示，避免关闭窗口后提示仍留在屏幕上。

## 升级

v0.1.14 用户可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。

## 验证

- 本地 macOS 完整构建及 10 组自动化测试通过。
- 已验证 macOS 原生搜索窗口的保持打开、关闭重开、浅深色布局、提示移除和会话生命周期。
