波形窗口新增通道数据列表和独立的倍率、偏移设置（#18）。

- 右侧列表显示通道颜色和最新值，可勾选控制曲线显隐，拖动分隔条调整列表宽度。
- 工具栏的“通道数据”按钮可展开或隐藏整个面板；隐藏时继续收数，重新展开立即显示最新值。
- “通道设置”默认收起，可独立展开；按“显示值 = 解析值 × 倍率 + 偏移”调整选中通道，也可一键重置。
- 倍率和偏移同步应用于已有曲线、新数据和 CSV 导出，各窗口相互独立。解析值保留，支持负倍率、零倍率以及调整后的恢复。
- 清空数据后按通道名称保留设置；更换解析配置或载荷模板后重置，关闭窗口后不保留。

## English

Plot windows now include a channel data list with independent scale and offset controls (#18).

- The list shows each channel's color and latest value. Checkboxes control curve visibility, and the divider adjusts the panel width.
- Use **Channel data** in the toolbar to show or hide the whole panel. Data keeps arriving while it is hidden, and the latest values appear as soon as it is shown again.
- **Channel settings** starts collapsed and expands independently. Adjust the selected channel using `displayed = parsed × scale + offset`, or reset it in one click.
- Adjustments apply to retained curves, incoming data, and CSV exports independently in each window. Parsed values are retained, so negative and zero scales can be reversed.
- Clearing data keeps settings by channel name. Changing the parser configuration or payload template resets them; closing the window discards them.
