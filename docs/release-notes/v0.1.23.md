# Fluent 串口助手 v0.1.23

- 设置中新增“云母效果”开关，Windows 11 上默认开启。
- 界面控件库升级到 FluentQtWidgets v0.2.0，控件尺寸和外观与 PyQt-Fluent-Widgets 一致。
- 选择导出文件夹改用系统的文件夹对话框。
- 应用标识改为 `io.github.txp666.FluentSerialAssistant`。macOS 上 v0.1.22 及更早版本无法在应用内更新到此版本，请从发布页手动下载一次。

## English

- New "Mica effect" switch in Settings, on by default on Windows 11.
- The UI library is updated to FluentQtWidgets v0.2.0, so controls match PyQt-Fluent-Widgets in size and look.
- The export folder is chosen with the system folder dialog.
- The app identifier is now `io.github.txp666.FluentSerialAssistant`. On macOS, v0.1.22 and earlier cannot update to this version from inside the app; download it once from the releases page.
