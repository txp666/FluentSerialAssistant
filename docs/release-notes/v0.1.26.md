修复组件库升级后出现的几处界面问题。

- 更新窗口的“稍后 / 取消更新”按钮恢复正常样式和大小；更新说明只显示界面语言的部分。
- 自动弹出的更新窗口不再响应回车，避免误触下载。
- 提示和状态文字恢复为灰色。
- 更换界面字体后立即全部生效；导入的字体在重启后用于界面，并有提示。
- 快速绘图的坐标刻度取整（FluentQtWidgets v0.3.2）。

## English

Fixes for interface issues that came with the component library upgrade.

- The update dialog's Later / Cancel button has its normal style and size again, and the release notes show only the part in the interface language.
- The update dialog that opens by itself no longer takes Return, so typing in the send box can't start a download.
- Hints and status lines are grey again.
- A new interface font applies everywhere at once; an imported font reaches the interface after a restart, with a notice saying so.
- The quick plot's axes tick on round steps (FluentQtWidgets v0.3.2).
