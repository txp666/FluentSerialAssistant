# Fluent 串口助手 v0.1.10

此版本建立完整的三平台安装包发布流程，并为 SignPath Foundation 免费开源代码签名做好准备。

## 发布包

- Windows x64：请求管理员权限并默认安装到 Program Files 的中英文 Inno Setup 安装程序。
- macOS ARM64：DMG 磁盘映像。
- Linux x64 / ARM64：DEB 安装包。
- 所有安装包均附带 SHA-256 校验文件。

## 发布与安全

- Windows 工作流会在 SignPath Foundation 审核通过后先签署 `FluentSerialAssistant.exe`，再构建并签署 Inno Setup 安装器。
- 首个新格式 Windows 安装器暂不包含 Authenticode 签名，用于满足开源签名申请所需的已发布安装包条件。
- 增加公开的代码签名政策、隐私政策和受版本元数据约束的 SignPath artifact configuration。
- 发布标签必须与 CMake 项目版本一致，工作流在发布前验证安装包和 SHA-256 校验文件。

## 配置兼容性

- Windows、macOS 和 Linux 统一使用系统标准用户配置目录，继续以 INI 文件保存业务配置且不写 Windows 注册表。
- 首次运行时自动迁移旧版安装目录中的配置，避免应用安装到 Program Files、`.app` 或 `/opt` 后无法保存设置。
- 增加英文版 README，并提供中英文文档互链。

## 验证

- Qt 6.11.1 macOS Release 全新配置及完整构建通过。
- ARM64 DMG 已实际生成，并通过 bundle 签名、镜像校验及挂载内容检查。
- Release YAML、SignPath XML、Bash 脚本语法和仓库差异检查通过。
