# Fluent 串口助手 v0.1.21

此版本让校验可以只覆盖帧的一部分：发送设置可跳过开头和末尾的字节，帧协议模板增加帧尾和校验起始偏移。同时修正自动追加校验时校验码排在换行符之后的问题。

## 发送校验范围

- “发送设置”新增“跳过字节”，分别设置开头和末尾跳过的字节数。校验只计算中间部分，校验码插在末尾跳过的字节之前。例如发送 `AA 55 01 02 03 7E`，开头跳过 2、末尾跳过 1 时，实际发送 `AA 55 01 02 03 [校验] 7E`。
- 发送框、常用包、宏、自动应答和脚本都使用这一范围；“计算”按钮也一样，结果中会显示覆盖的字节。
- 跳过后没有可校验的字节时，会提示原因且不发送。
- 设置会保存，新建会话沿用当前设置。两项都为 0 时，校验范围与以前相同。

## 帧协议模板

- 新增“帧尾”：校验之后的固定字节，如 `0D 0A` 或 `03`。帧尾计入整帧长度，接收的帧尾不符时提示“帧尾不匹配”。
- 校验字段新增“起始偏移”：校验从该字节计算到校验前一字节，例如设为 2 可不计入两字节帧头。
- 编辑器预览用颜色标出帧尾，并显示校验覆盖的字节范围。
- 已保存的模板没有这两项设置，保持原有行为。

## 修复

- 自动追加校验时，换行符现在始终在校验码之后，且不参与计算。此前文本加 CRLF 会发送 `数据 0D 0A 校验码`，现在发送 `数据 校验码 0D 0A`。

## 升级

v0.1.14 及更新版本可在应用内检查更新，查看更新内容并确认后下载和安装。v0.1.13 及更早版本请从发布页手动下载安装包。
